# Repository hosting

Development happens on GitHub at [github.com/openape-ai/claude-plugin-openape-chat](https://github.com/openape-ai/claude-plugin-openape-chat). Clone, branch, push and open pull requests there:

```sh
git clone git@github.com:openape-ai/claude-plugin-openape-chat.git
```

The former hosts repos.openape.ai (ape-git) and git.openape.ai (Forgejo) were retired in November 2026. Their repository URLs redirect to GitHub and refuse pushes; existing clones should set `origin` to the GitHub URL above.
